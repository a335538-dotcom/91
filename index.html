Section 05 / Cycle
月經週期
女性身體是週期系統 / 動態調整強度
點擊每個週期查看詳細訓練建議。濾泡期是全力衝刺的最佳時機，黃體期則需要主動降強度。
第1週 / 約 Day 1–5
🔴 月經期
›
雌激素低 / 容易疲勞疼痛 / 身體在修復
暫停高強度訓練
改為瑜伽、散步、簡單伸展或滾筒放鬆
經痛劇烈請直接休息，不強迫自己動
第2週 / 約 Day 6–13
🟢 濾泡期 — 全力衝！
›
雌激素上升 / 體力耐力情緒達巔峰 / 最佳訓練時機
增加訓練量與強度的最佳時機！
全力執行大重量訓練（5–8RM）
適合挑戰個人最佳成績（PR）
加入高強度間歇訓練
第3週 / 約 Day 14±2
🟡 排卵期 — 穩定輸出
›
雌激素高峰 / 韌帶暫時鬆弛 / 受傷風險提高
絕對不要挑戰1RM（個人最佳）
移除課表中的高衝擊跳躍動作
嚴格執行暖身，動作控制要精準
感疲憊或排卵痛→立刻降為中等強度
第4週 / 約 Day 15–28
🟠 黃體期 — 動態評估
›
體溫升高 / 疲勞感增加 / 可能有經前症候群
執行「10分鐘原則」：暖身10分鐘若無改善立刻降強度
月經快來前幾天→主動設為減量週
大幅降低訓練量與重量
睡眠優先，不強迫自己
